# PriceTracker

Расширение для Chromium-браузеров для отслеживания цен на товары в интернет-магазинах.

PriceTracker сохраняет ссылки на товары, периодически считывает актуальные цены прямо со страниц магазинов, хранит историю изменений и показывает всё в одной таблице.

Проект рассчитан в первую очередь на личное использование и пока находится в разработке.

## Возможности

- добавление товара прямо с его страницы;
- автоматическое определение поддерживаемого магазина;
- сохранение текущей цены;
- история изменений цены;
- собственное название товара;
- целевая цена;
- выделение товаров, достигших целевой цены;
- сортировка товаров по изменению цены;
- группировка по магазинам;
- ручная перестановка магазинов в таблице;
- обновление:
  - всех товаров;
  - отдельного магазина;
  - отдельного товара;
- отображение ошибок обновления без потери последней известной цены;
- экспорт и импорт резервной копии в JSON.

## Поддерживаемые магазины

Сейчас реализованы адаптеры для:

- Пятёрочки;
- Глобуса;
- Дикси;
- Яндекс Лавки;
- Smart;
- Магнита;
- Ozon;
- Wildberries;
- DNS.

Поддержка зависит от текущей структуры сайтов. Если магазин изменит разметку страницы, соответствующий адаптер может потребовать обновления.

## Как работает обновление

PriceTracker не использует единый API магазинов.

Для обновления расширение открывает страницу товара в служебной вкладке, ждёт появления необходимых данных и считывает название и цену через адаптер соответствующего магазина.

Для разных сайтов используются разные источники данных:

- DOM страницы;
- semantic/meta-элементы;
- JSON-LD;
- структурные признаки ценовых блоков.

Селекторы и логика разбора каждого магазина находятся в общем реестре адаптеров.

### Параллельное обновление

Товары одного магазина проверяются последовательно, чтобы не создавать сразу большое количество вкладок одного сайта.

Разные магазины могут обновляться параллельно.

Одновременно запускается до четырёх store-worker'ов.

Перед полным обновлением магазины сортируются по количеству отслеживаемых товаров: самые большие очереди стартуют первыми. Это уменьшает вероятность длинного хвоста, когда после завершения остальных магазинов остаётся один крупный список.

## Таблица результатов

Товары разбиваются на отдельные секции по магазинам.

Для каждого товара отображаются, в частности:

- название;
- текущая цена;
- предыдущая цена;
- изменение;
- целевая цена;
- время последнего обновления;
- статус;
- действия.

Доступные действия:

- редактировать название и целевую цену;
- удалить товар;
- обновить только этот товар.

Порядок магазинов можно менять непосредственно на странице результатов.

## Сортировка товаров

Внутри магазина товары автоматически сортируются по состоянию:

1. достигнута целевая цена;
2. цена снизилась;
3. нейтральное состояние или недостаточно истории;
4. цена выросла;
5. ошибка обновления.

Внутри одной группы используется сортировка по названию.

## Резервные копии

PriceTracker умеет экспортировать данные в JSON и восстанавливать их обратно.

В резервную копию входят:

- товары;
- история и сохранённые данные товаров;
- пользовательские названия;
- целевые цены;
- порядок магазинов.

Временный статус текущего обновления в backup не сохраняется.

Пример структуры:

```json
{
  "format": "PriceTrackerBackup",
  "version": 1,
  "exportedAt": "2026-09-12T12:00:00.000Z",
  "products": [],
  "storeOrder": []
}
```

## Установка

Пока расширение устанавливается вручную из исходников.

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `PriceTrackerExtension`.

После изменения `manifest.json` расширение необходимо перезагрузить кнопкой **Reload / Обновить** на странице расширений.

## Использование

### Добавление товара

1. Откройте карточку товара в поддерживаемом магазине.
2. Нажмите на значок PriceTracker.
3. Проверьте найденные название и цену.
4. Добавьте товар.

### Обновление

На странице результатов можно:

- обновить весь список;
- обновить только конкретный магазин;
- нажать `↻` у отдельного товара.

Во время полного или магазинного обновления одиночные обновления временно блокируются.

## Архитектура

Основные файлы проекта:

- `manifest.json` — Manifest V3 и разрешения расширения;
- `store-adapters.js` — определение магазинов, селекторы, чтение названий и цен, readiness;
- `popup.js` / `popup.html` — добавление текущего товара;
- `background.js` — открытие служебных вкладок, обновление товаров, scheduler и работа с хранилищем;
- `results.js` / `results.html` — таблица результатов, сортировка, редактирование, импорт и экспорт.

`store-adapters.js` служит единым источником логики конкретных магазинов. Popup и background не должны содержать собственные копии селекторов.

## Хранение данных

Данные сохраняются локально через `chrome.storage.local`.

PriceTracker не требует собственного сервера для хранения списка товаров и истории.

## Ограничения

Проект зависит от клиентской разметки сторонних сайтов.

Возможные причины ошибки обновления:

- магазин изменил DOM или JSON-LD;
- страница загружается слишком долго;
- товар снят с продажи или временно недоступен;
- сайт показывает другую версию страницы для региона или аккаунта;
- CAPTCHA или антибот-защита;
- сетевые ошибки.

При ошибке последняя успешно полученная цена не удаляется.

## Разработка

node --check popup.js

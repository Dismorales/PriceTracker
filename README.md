# PriceTracker

Небольшое браузерное расширение для отслеживания цен на выбранные товары в продуктовых магазинах.

Товар добавляется прямо со страницы магазина, после чего PriceTracker может самостоятельно пройти по сохранённым карточкам, получить актуальные цены и показать изменения.

> **Статус:** проект находится в разработке (`0.9.x`).  
> Основной функционал уже работает, но адаптеры магазинов могут ломаться при изменении их сайтов.

## Поддерживаемые магазины

- Пятёрочка
- Глобус
- Дикси
- Яндекс Лавка
- Smart
- Магнит

## Возможности

- добавление товара прямо с его страницы;
- автоматическое определение поддерживаемого магазина;
- обновление всех сохранённых цен;
- отдельное обновление выбранного магазина;
- история изменения цены;
- отображение предыдущей цены;
- минимальная зафиксированная цена;
- пользовательская целевая цена;
- подсветка товаров, достигших целевой цены;
- сортировка товаров по приоритету и изменению цены;
- группировка товаров по магазинам;
- настраиваемый порядок магазинов;
- быстрое перемещение между секциями магазинов;
- редактирование названия товара и целевой цены;
- удаление товаров;
- экспорт и импорт резервной копии в JSON.

## Установка

Пока расширение устанавливается вручную в Chromium-браузер.

1. Скачать или клонировать репозиторий.
2. Открыть страницу расширений браузера:

   `chrome://extensions/`

3. Включить **Режим разработчика**.
4. Нажать **Загрузить распакованное расширение**.
5. Выбрать папку `PriceTracker`.

После установки расширение можно закрепить на панели браузера.

## Использование

### Добавление товара

1. Открыть карточку нужного товара в поддерживаемом магазине.
2. Открыть PriceTracker.
3. При необходимости указать целевую цену.
4. Добавить товар.

PriceTracker сохранит ссылку, название, магазин и текущую цену.

### Обновление цен

На странице результатов можно обновить:

- все товары сразу;
- только товары конкретного магазина.

Карточки товаров проверяются последовательно, чтобы не открывать большое количество страниц одновременно.

### Целевая цена

Для товара можно указать цену, при достижении которой он будет выделен в списке.

Цель можно изменить или удалить в любой момент.

### Резервная копия

На странице результатов доступны:

- **Экспорт JSON**
- **Импорт JSON**

Резервная копия содержит список товаров, историю цен, целевые цены, пользовательские названия и порядок магазинов.

## Как работает получение цен

PriceTracker использует отдельный адаптер для каждого магазина.

В зависимости от сайта цена может извлекаться из:

- семантической разметки Schema.org / JSON-LD;
- стабильных `data-*` атрибутов;
- DOM-элементов карточки товара.

Сгенерированные CSS-классы по возможности не используются.

Адаптеры находятся в:

`store-adapters.js`

Поэтому поддержку нового магазина можно добавить, не переписывая основную логику расширения.

## Ограничения

PriceTracker зависит от структуры сайтов магазинов.

Если магазин изменит разметку карточки товара, его адаптер может временно перестать находить название или цену.

Также цены на сайтах могут зависеть от выбранного магазина, города, аккаунта пользователя или других условий. PriceTracker сохраняет ту цену, которую получает на открываемой карточке товара.

## Данные

Все данные PriceTracker хранятся локально в `chrome.storage.local`.

Расширение не использует собственный сервер и не требует регистрации.

JSON-бэкапы пользователя не входят в репозиторий и исключены через `.gitignore`.

## Разработка

Основные файлы:

| Файл | Назначение |
|---|---|
| `manifest.json` | конфигурация расширения и разрешения |
| `popup.html` / `popup.js` | добавление текущего товара |
| `background.js` | фоновое обновление сохранённых товаров |
| `store-adapters.js` | адаптеры поддерживаемых магазинов |
| `results.html` / `results.js` | список товаров, история, управление и обновление цен |

Проект написан на обычных HTML/CSS/JavaScript без сторонних библиотек.
